Configuração do banco

O aplicativo usa o Cloud Firestore do projeto informado.

Se o Firestore ainda não estiver criado, acesse o Console Firebase, crie o banco no modo de produção e publique as regras abaixo.

Como não existe login, essas regras permitem acesso ao banco por qualquer pessoa que conheça a configuração do projeto. Para uso pessoal, mantenha o endereço do app privado e considere ativar o Firebase App Check. 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /rifas/{rifaId} {
      allow read, write: if true;
      match /compradores/{compradorId} {
        allow read, write: if true;
      }
    }
  }
}
